# AI Animation Prompt Packs

Free prompt packs from my videos on making animated scenes with **Claude**, **Google Flow** (Nano Banana Pro + Veo 3.1) and **ElevenLabs**.
Every prompt is copied from the real production. Copy them, swap in your own character, and make your own scene.

Each pack has the character prompt, the identity bracket, every keyframe prompt, the 8-second beat formula, the final video prompts, the takes that broke with the lock sentences that fixed them, the dialogue prompt and the cost sheet.
